# Comparison with prior Studio experiments

No SDLXLIFF was created or modified. The prior Phase 2B/3G/4A experiments establish the relevant projection constraints:

- native tables remain identifiable through Studio;
- one logical table-cell paragraph remains one source unit when serialized with controlled line breaks;
- empty structural cells need not create translatable units;
- Studio sentence segmentation is distinct from DOCX paragraph/TU boundaries.

The canonical model retains those distinctions before any CAT projection. It does not claim a new Studio result. The 265 canonical TUs are source-document units, not predicted Studio CAT segments.
